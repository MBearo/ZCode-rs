# Rust stdio 剩余对齐清单

2026-09-22，目标是替换 App 使用的 stdio runtime。权限只支持 yolo，不做 TUI；默认仍为 TS，Rust 显式选择。用户指定的关键工作包已实现并经过核心验收，不能再把 MCP、Skill、子代理、Goal 和历史操作笼统列为“未实现”。证据见 [核心交付报告](../reports/rust-critical-parity-2026-09-22.md)。
